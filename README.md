# Django

*Mini-projekty w Django tworzone w ramach nauki frameworka.*

![Python](https://img.shields.io/badge/Python-3.8.1-3776AB?logo=python&logoColor=white)
![Django](https://img.shields.io/badge/Django-3.1-092E20?logo=django&logoColor=white)

## 📖 Opis

Dwie niezależne aplikacje Django tworzone jako ćwiczenie z frameworka: blog i serwis zakładek z systemem kont użytkowników.

## 📂 Struktura

| Folder | Zawartość |
|---|---|
| `mysite/blog/` | Aplikacja bloga: posty, komentarze, tagi, feed RSS, wyszukiwarka, sitemapa |
| `mysite/bookmarks/` | Aplikacja do zapisywania zakładek z kontami użytkowników (rejestracja, logowanie, reset hasła) |
| `mysite/polls/` | Aplikacja ankiet (przykładowy projekt z oficjalnego tutoriala Django) |
